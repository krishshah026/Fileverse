# Fileverse is starting in this codespace

The first start takes a few minutes. Fileverse opens in a new browser tab when it's ready.

**If it didn't open:** click the **Ports** tab at the bottom → hover port **8080 (Fileverse)** → click the 🌐 globe icon.

- **Private by default.** Only you (signed in to GitHub) can open the link.
- **To share it with someone:** Ports tab → right-click 8080 → Port Visibility → Public.
- **When you're done:** github.com/codespaces → ⋯ → Stop codespace (saves your free hours).
- **Next time:** github.com/codespaces → click this codespace → Fileverse starts again by itself.
- **Get the latest version after code changes:** run `bash .devcontainer/start.sh --update` in the terminal.

Free GitHub accounts include 60 hours a month on this 2-core machine. Converted files are deleted after 2 hours.
